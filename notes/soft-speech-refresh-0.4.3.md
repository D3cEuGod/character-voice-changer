# 0.4.3 句首、轻声与自动重开

用户明确指出：已转换出的声音清楚，但句首、轻声有时整段不输出。此前只测电平 / WebSocket 握手，无法确认这些部分是否完整，因此这次同时检查门控、实际虚拟麦克风和 Discord 接收设置。

## 改动

- Silero 以 .35 开启、.12 关闭；置信度不再直接缩放波形，保留已开启后的轻声。保留 96 ms 句首上下文，句尾保留 240 ms，不增加流式播放前瞻。
- 降噪后满增益门槛从 RMS .00175 降到 .00065；不再在模型输入与输出重复乘语音活动掩码。极低能量快速返回门槛从峰值 .0006 降到 .0001。GTCRN、RVC 权重、音高和播放缓冲未变。
- 3,000 / 5,000 包成为刷新请求：等待输入 RMS < .003、转换回包 RMS < .001 连续 600 ms，完成尾音后关闭采集 / 输出 / WebSocket。GUI 等旧线程结束及 250 ms 设备间隔，再启动。手动停止、退出和旧回调都有取消保护。
- 自检增添新会话实际输出与独立 CABLE Output 回录；修正 VB-CABLE 16ch 别名可能被当作输入馈送、造成测试反馈的问题，强制用另一根 Steam 虚拟线喂入合成语音。

## 对照

基线 b485a64（0.4.2），相同本地三条 RVC、120 ms 包、音色优先、强度 100%、自动音域再 +4。同一句 Windows Kangkang 合成男声（回归集 m2），固定种子底噪 RMS .0015，句前、句后各 1 秒。

| 条件 | 输入 | 修改前错字 | 修改后错字 |
| --- | --- | --- | --- |
| 普通音量 | 全句 RMS .02 | 3/66 | 4/66 |
| 轻声句首 | 前 .9 秒缩到 30% | 8/66 | 6/66 |
| 全句轻声 | 全句 RMS .006 | 9/66 | 7/66 |

三条声线每条件各 22 字。SenseVoice 自动识别会出错，少数几个字不能代表人类听感；这些数据也不证明与角色更相似。该测试不含 Discord 编解码和远端听感。

另测了语音缩到 7.5%（RMS .0015，与噪声相当）的极端输入。只降低门槛会放出更多失真的字；模型分析输入额外放大、混入 35% 原输入等实验也没有稳定改善，**没有纳入发布代码**。先前提到的句首增益约 8% → 69% 仅为该极端条件下门控系数变化，不是清晰度提升或音频还原率。

额外风扇启动与键盘脉冲测试中，键盘独立输入三声线输出都为零。风扇启动仍会误触发：塔菲整段输出 RMS .01071 → .00920，爱音 .02527 → .01139，灯 .00313 → .00844。灯有退化，不能宣称噪音问题完全解决；保留原始指标便于继续调节。

## 实际设备与验证

- 用户说话时仅在内存统计 WO Mic、CABLE Output 电平，没有保存用户语音。输入与虚拟麦克风都有信号，因此不能将本次问题归为完全断线。
- Discord 原输入已经正确选为 CABLE Output，但 Input Profile 为 Voice Isolation。现场改为 Studio 并确认选中；保持用户静音。Studio 适用于接收已经处理过的变声器输出，也符合 [Voicemod 官方接入建议](https://support.voicemod.net/hc/en-us/articles/360013438419-How-to-set-up-Voicemod-on-Discord)。这项设置只作用于本机 Discord。
- 16 项刷新与停止竞态、6 项门控、6 项音高、1 项流式样本守恒测试通过。
- 最终真实 GUI / 后端自检 **80 通过、0 失败、1 跳过**（跳过另外启动第二个后端，测试复用 8766）。刷新阈值临时设为 12 包，生产仍是 3,000 包。新会话 22 包有输入 / 输出，CABLE Output 连续录回截掉新连接前 .7 秒后，仍有 2.42 秒合成语音，RMS .0520。
- 首轮自检误用 VB-CABLE 的 16ch 别名作源，4 项无信号失败；修正馈送线后有信号，第二轮仅剩旧固定时长断言失败（120 ms × 18 包不足原 2.5 秒要求）。改按协商帧长检查后最终通过，失败轮没有当作后端无信号或性能证据。

## 仍有限制

还需要用户解除静音后让朋友确认真实轻声 / 句首，不能用本机回录替代远端验证。自动重开在物理设备关闭时仍不能采集声音，释放期间新开始说的一句可能丢失；它不是无缝热切换。持续讲话或背景高于安静门槛时会延后刷新。本次没有完成小时级长通话测试。

原始合成回归指标与识别文本见 `evaluations/soft-speech-0.4.3.json`，最终自检见 `evaluations/selfcheck-0.4.3.log`。
