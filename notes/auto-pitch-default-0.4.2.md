# 0.4.2：女性角色默认自动音域再 +4

2026-11-14，按用户明确选定的效果，让当前三个女性角色的 GUI 默认档改为自动音域再 +4。从界面下拉框和 `--pitch-preset` 中移除 `fixed4`；现在只有 `model` 和 `auto4`，后者是启动默认。

三位目前的模型配置都是自动音域匹配，所以自动后再 +4 的目标大致为灯 403 Hz、塔菲 541 Hz、爱音 391 Hz（100% 强度，仍保留说话的音调起伏和原有 650 Hz 上限）。角色切换、两种处理方式、文件转换、实时会话重连和每 3,000 包刷新后保留选择。权重、索引、包长与缓冲设置未改变。

当前三份 [试听](../assets/pitch-comparisons/) 已按两段重生成：0.000–5.262 s 为模型默认，5.862–11.124 s 为自动音域再 +4，中间间隔 0.6 s。输入仍是已保存的同句合成男声；固定原声 +4 的段已经移除，参数与哈希见目录内 `manifest.json`。0.4.1 的三段式历史留在 Git 对应版本中。

低层 RVC 的通用 `pitch_shift` 参数与导入器仍兼容旧客户端，但 GUI 不再有固定原声 +4 的预设。普通双击即为所选默认；需要恢复原自动匹配时选“模型默认”。

验证：

- 真实 GUI / Steam 音频自检 78 项通过、0 失败、1 跳过（另起第二个后端）。逐一确认三位角色默认 `auto4`、列表只有两项且无 `fixed4`；文件结果关联和实时握手、周期刷新保留音高的检查通过。
- 6 项音高单元测试通过，已检查删除的预设不能再生成请求。
- 3 角色 × 2 档的真实协议检查通过，握手回显 `pitch_shift=null, pitch_offset=4`；16 次 HTTP / WebSocket 非法参数请求仍被拒绝。
- 原始小型摘要在 `evaluation/0.4.2/`。本轮自检输出走 Steam Streaming Speakers，未向 VB-CABLE 播放自检音频。

新增的 ZmjjKK 模型线索和检索限制另见 [检索记录](zmjjkk-search-2026-11-14.md)。没有把网页上的 AI 翻唱示例当成已经可下载的模型。
